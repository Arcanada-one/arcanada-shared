# Producer source lock for the four native adapters (KCLIVE-01, gate G2)

**Status:** evidence record, source inspection only. No adapter is implemented or marked implemented by this document. Every runtime predicate is `NOT_MEASURED`. Read-only inspection of default-branch HEAD on 2026-11-07; no producer repository, production datum or deployed service was changed or read.

**Why:** the Agent-Brain decision (mail 7ca32ce8) requires each adapter to have its exact native source locked before it is marked implemented. The profile preparation in the workspace (`SEMANTICS.md`, `SOURCE-LOCK.json`) is _not_ a native schema implementation; this record is the native-side lock. Maps to the envelope in [`knowledge-observation-v1.md`](knowledge-observation-v1.md).

**Visibility note:** Doclab, Argana and `talomnia-knowledge` are private repositories. Only repository, commit, path, git blob SHA and symbol or test names are recorded here, never their contents. Blob SHAs are `git rev-parse <commit>:<path>`.

## 3. What each adapter test would assert

| Producer | Positive                                                                                                                                             | Contradiction or refusal                                                                                                          |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Muneral  | A native journal of three versions (issued, started, succeeded) maps to three events with distinct `aggregateVersion` and `Task.revision` kept apart | A version gap holds state and never advances the cursor; a terminal `done` stays `NOT_MEASURED` for acceptance                    |
| Doclab   | A run filter yields event ids 100 and 104 as adjacent observations and no loss is inferred                                                           | The same id with different bytes is a conflict; a B2-shaped run with a missing `run_inserted_finished` event is not classed as B2 |

## 4. Limits

- Inspection is of default-branch HEAD of each repository, by shallow clone. It is not a deployed build, and no deployment was queried.
- Tests were cited by name. Only the Doclab adapter tests were run (12 passed). The Muneral, ARAS, Argana and knowledge-contract tests were not run.
- Whether the Muneral relay is enabled in production, and whether ARAS ever runs with a real authority, are `NOT_MEASURED`.
- The adapters' final form (a package in this repository or the producers' own repositories) is not decided here.
